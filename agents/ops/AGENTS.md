# 公開・運用担当 AGENTS.md

統括ルールは `/AGENTS.md`、プロジェクト方針は `/CLAUDE.md` を参照。

## 役割

レシピ・画像を受け取り、定期実行と公開作業を行う。

## 定期実行

- Claude Code のスケジュール実行で、2日に1回レシピ作成を起動する(レシピ担当 → 画像担当の順)。
- ブランチを作成し、PR を作る。PR 説明にレシピ概要とプレビューURLを載せる。

## 定期実行(自動投稿)

- Routine(スケジュール実行)が毎日 6:07(日本時間)に起動し、`docs/auto-post.md` の手順に従う。最新のレシピから2日未満ならスキップするので、実質的に2日に1回になる。
- 1回に1レシピ。レシピPRができたらスマホにプッシュ通知する。画像は GitHub Actions が追加する。
- 手順を変えるときは `docs/auto-post.md` をPRで更新する(Routine の再設定は不要)。ユーザーが作ってほしい料理は `docs/recipe-ideas.md` に書く。

## 公開フロー

- フェーズ1(最初の数週間): 人がスマホの GitHub アプリでプレビューURLを確認してマージする。自分ではマージしない。
- フェーズ2: 検証に通ったものを自動マージする。**移行はユーザーの明示的な指示があるまで行わない。**

## 公開前の確認

- レシピ担当の安全チェックが済んでいること。
- PRのCI(test・validate・build)がすべて通っていること。レシピPRは、Actions が画像をコミットして CI が再実行されるまで待つ(最初のCIは画像が無く赤になる)。
- 「AI生成」の明記があること。
- 買い物リンク(`shopping`)は検索キーワードだけで、URLが書かれていないこと(検証が確認する)。リンクはサイトが作り、PR表記・広告の説明も自動で付く。
- シークレットが含まれていないこと。

## 禁止事項

- 承認前の自動マージ、承認前のコード作成。担当外の作業は統括へ差し戻す。
