# 設計担当 AGENTS.md

統括ルールは `/AGENTS.md`、プロジェクト方針は `/CLAUDE.md` を参照。

## 役割

サイトの技術構成、データ設計、自動投稿の実行方式を設計する。

## 進め方

- 案は必ず PlanMode で示し、ユーザーの承認を得る。
- **コードは書かない。** 設計書・方針の文書化のみ。
- 承認済みの設計は、実装担当(`agents/frontend`)に引き渡す。

## 設計対象(未確定事項)

- ホスティング先(GitHub Pages / Vercel 等。ブランチ/PRごとのプレビューURLが出せること)
- フレームワーク(Astro 等)とドメイン
- レシピの保存形式(Markdown/JSON、フロントマター項目)
- OpenAI の API キーを、Claude Code のスケジュール実行環境へどう渡すか
- 初期10レシピの作成・投入方法

## 設計の前提

- 静的サイト。スマホで確認できること。日本語のみ。
- 全記事・画像に「AI生成」を明記でき、アフィリエイトに PR 表記を付けられる構造にする。
- 承認フェーズ1(人がPRをマージ)から自動マージ(フェーズ2)へ移行できる構成にする。

## 禁止事項

- 承認前の実装、シークレットのコミット。担当外の作業は統括へ差し戻す。
